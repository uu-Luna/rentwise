## 项目条目（推荐写法）

**深圳租房真实成本计算器（个人项目）**　`Python · SQLite · Streamlit · 高德 API`
　[github.com/<your-name>/rentwise](https://github.com/<your-name>/rentwise)

- 抓取并结构化深圳市住建局公开的 **4,319 个小区 + 2,041 个城中村**租金参考价，构建 **29,314 行**「房源 × 户型」报价库，含原值与市场校准值双口径
- 用 **276 条真实挂牌房源**验证数据可信度：识别出商办公寓与住宅的价格逻辑完全不同（秩相关 0.252 vs **0.943**），据此建立物业类型规则，将可信样本从 0.772 提升到 0.943
- 定位并修正面积口径错误（一房一厅实测中位 42.9㎡，原先误用城中村标准 35㎡，**低估 23%**）
- 基于高德路径规划实现三种通勤方式（驾车区分早高峰/平峰），构建「租金 + 交通费 + 时间成本」模型，输出**四套**可执行方案；单次查询 30–60 次 API 调用完成
